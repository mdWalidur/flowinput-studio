# FlowPoint landing page redesign

## Scope
Redesign only the public landing page and the brand elements it directly uses. Preserve the existing workspace, transformations, saved work, parsing, and route behavior.

## Visual direction
- Establish FlowPoint as a calm editorial instrument: high-contrast typography, generous whitespace, thin rules, asymmetrical layouts, and a restrained ink / paper / signal palette.
- Replace the current document-like mark with a recognizable point-and-direction path motif and update landing-visible brand naming to FlowPoint.
- Keep surfaces flat and precise; avoid SaaS card grids, glow effects, glass, and decorative gradients.
- Use Motion for short staged reveals and purposeful flow transitions, with reduced-motion support.

## Landing page
- Build a sparse FlowPoint header with Workspace, My work, Settings, and “Open FlowPoint”.
- Create a typography-led hero around “Turn what you have into what’s next.”, the “Where the flow begins.” tagline, direct calls to action, and the accurate local/no-account status.
- Add an interactive product artifact showing one source entering a decision point and branching into useful outputs.
- Render START → UNDERSTAND → DIRECT → TRANSFORM → VALIDATE → RESULT as one connected visual sequence.
- Present the five existing goals as an interactive typographic index linked to their current workspace searches.
- Demonstrate one source branching to several outcomes without claiming new transformation capabilities.
- Add concise, honest local-first and deterministic-processing language, followed by a strong final call to action.

## Brand and metadata
- Update landing-visible name, promise, tagline, mark, and landing-page SEO metadata to FlowPoint.
- Keep links, canonical handling, structured data, sitemap behavior, and all existing destinations working.
- Do not modify workspace/result logic or introduce backend, OCR, or live-AI claims.

## Verification
- Check desktop and mobile layouts, keyboard interaction, reduced-motion behavior, metadata, route links, and browser console/runtime health.
